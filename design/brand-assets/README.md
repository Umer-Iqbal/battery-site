# Enersol brand assets

Everything here is generated by `./generate.sh` from one set of path
coordinates, so nothing can drift. Re-run it after any change to the mark.

    ./generate.sh          # needs rsvg-convert + ImageMagick

The mark geometry mirrors `src/components/brand/logo-paths.ts`. If you change
one, change the other.

## Which file do I use?

| Where | Use |
|---|---|
| Social profile picture (Facebook, Instagram, LinkedIn, YouTube, WhatsApp) | `app-icon/enersol-appicon-dark-400.png` — or `-light-` / `-blue-` |
| App store / launcher icon | `app-icon/enersol-appicon-dark-1024.png` |
| Website favicon | `../../public/brand/favicon.svg` (already wired) |
| Anywhere needing a `.ico` | `favicon.ico` |
| Letterhead, invoice, email signature | `lockup/enersol-lockup-white-1800.png` |
| On a dark background | `lockup/enersol-lockup-dark-1800.png` or `mark/enersol-mark-white-1024.png` |
| Placed over a photo or colour | `lockup/enersol-lockup.svg` (transparent) |
| Single-colour print, stamps, embroidery | `mark/enersol-mark-black.svg` |
| Link preview when the site is shared | `social/og-image-1200x630.png` (already wired) |
| Signwriting, vehicle wrap, anything scaled large | any `.svg` — never the PNGs |

Profile pictures get cropped to a circle on most platforms. The app-icon files
already keep the mark well inside a safe area, so the corners are all that get
lost.

**Prefer the SVGs** wherever the tool accepts them. They are a few hundred
bytes and stay sharp at any size.

## Contents

- `mark/` — symbol only, transparent. Brand colour, all-black and all-white
  versions, plus PNGs at 16 / 32 / 64 / 180 / 512 / 1024.
- `app-icon/` — symbol centred on a solid rounded square, for anywhere that
  needs a square image with no transparency. Dark, light and blue.
- `lockup/` — symbol plus the ENERSOL wordmark. Transparent, on white, on
  near-black.
- `social/` — 1200x630 link-preview card.
- `favicon.ico` — 16/32/64 in one file, for older browsers and CMSes.

## Known limitation: the wordmark font

The brand font is **Outfit** (what the website uses). It is not installed on
the machine that generated these files, so every raster with lettering in it —
everything in `lockup/` and `social/` — fell back to a system sans. The shapes
are close but not identical to the site.

The `mark/` and `app-icon/` files are pure geometry and are unaffected. They
are exact.

To get exact lockups:

    brew install --cask font-outfit
    ./generate.sh

Outfit is free (Google Fonts, SIL Open Font License). Until then, treat the
lockup rasters as good-enough for internal use and regenerate before anything
goes to print.
