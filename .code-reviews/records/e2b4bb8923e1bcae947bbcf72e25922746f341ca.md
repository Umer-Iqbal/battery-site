### Low (3)
- **scripts/prerender-routes.mjs:97** — `withRouteMeta` puts escaped title, description and URL into `String.replace` replacement strings, but `escapeHtml` doesn't neutralise `$`. *(correctness)*
  - status: fixed
  - dev_reasoning: N/A
  - ai_reasoning: Fixed: `withRouteMeta` now calls `out.replace(re, (_, prefix) => prefix + value)`. A function replacer never reads `$` patterns, and every regex has the capture group it needs. Original issue: if a product description or title contains `$&`, `$1`, `` $` `` or `$'` (for example a USD price like "$1,200"), `replace` reads it as a substitution pattern. The prerendered meta tag then comes out corrupted, with no error. Current data has no `$`, so this has no effect today. Fix: use a replacer function (`out.replace(re, (_, p1 = '') => p1 + value)`) or escape `$` as `$$`.
